# SOC-in-a-Box dashboard

React and Vite dashboard for the SOC-in-a-Box API. It displays agent status, log activity, incidents, notifications, and audit information.

## Development

```bash
npm install
npm run dev
```

The dashboard is served at `http://localhost:5173`; the API is expected at `http://localhost:8080`. For the full local setup, see the repository root [README](../README.md).
